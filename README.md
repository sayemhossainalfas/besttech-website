**Best Tech Website**
Best Tech ecommerce website built with Next.js, PostgreSQL, and Drizzle ORM.

## Features

- Public ecommerce storefront
- Product catalog and product details
- Cart and checkout flow
- Dealer and wholesale inquiry pages
- Admin dashboard
- Product, brand, category, slider, and blog management
- Best Tech branded invoice creator
- Print / Save as PDF invoice layout
- PostgreSQL database schema with Drizzle ORM

**Tech Stack**
- Next.js
- React
- TypeScript
- PostgreSQL
- Drizzle ORM
- CSS
